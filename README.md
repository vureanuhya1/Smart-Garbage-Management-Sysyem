# Smart Garbage Management System

A web-based application developed to improve garbage collection and waste management in cities and communities.

## Features

* Citizen registration and login
* Report garbage-related complaints
* Track complaint status
* Worker login and dashboard
* View and manage assigned complaints
* Admin dashboard
* Manage complaints and workers
* Generate and view reports

## Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python Flask
* **Database:** MySQL
* **Version Control:** Git and GitHub

## Project Modules

* Citizen Module
* Worker Module
* Admin Module
* Complaint Management Module
* Reports Module
* Database Module

## Project Team

Smart Garbage Management System is developed as a team project.

## Status

Frontend development is completed. Backend and database integration are currently in progress.
